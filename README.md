# Personal Portfolio Website

A static, single-page portfolio website built with plain HTML, CSS, and JavaScript. Features a deep navy/gold/emerald design, responsive layout, scroll-reveal animations, and full bilingual support (English and Persian) without page reloads.

## Features
- **Zero Dependencies:** Pure HTML/CSS/JS, no frameworks or build steps required.
- **Bilingual (EN/FA):** Instant language switching using a JavaScript dictionary and localStorage persistence, with full RTL support and custom typography (Vazirmatn for Persian, Inter for English).
- **Responsive Design:** Optimized for all screen sizes down to 375px.
- **Scroll Animations:** Lightweight custom intersection observer setup.

## Deployment on GitHub Pages

This project is formatted to deploy directly to GitHub Pages for free.

1. Create a new repository on your GitHub account (e.g., `portfolio-site`).
2. Push the contents of this folder into that repository on the `main` branch.
3. In your GitHub repository, go to **Settings** > **Pages** (in the left sidebar).
4. Under the **Build and deployment** section, select **Deploy from a branch** as the source.
5. Select the **main** branch and **/ (root)** folder. Click **Save**.
6. Wait a few minutes, and GitHub will provide you with a live URL where your site is published!
